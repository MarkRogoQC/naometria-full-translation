## Key Pattern

Nearly all garbled entries originate from one OCR failure mode: the gpt-4o-mini model's Fraktur recognition confused long-s (ſ) for various letters (j, i, f), and mixed up similar-looking Fraktur characters. The common substitutions:

- **Na** → **Nai** (Navarrae → Naiaræa)
- **Ge** → **Je** (Germani → Jernadi)
- **Ce/Cr** → **Ct** (Creationis → Cretitions)
- **us** → **i** (Regnum → Regnimi)
- **ti** → **ie** (Martyrii → Marterij)
- **v** → **iu** (Nativitas → Natina)
- **t** → **i** (Petri → Peice)
- **s** → **i** (Jesus → Jeius)
